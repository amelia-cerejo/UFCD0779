Ferramentas de Texto, Desenho e Gráficos

Explora as ferramentas de desenho, inserção de imagens, gráficos e tabelas do PowerPoint — enriquece visualmente os teus diapositivos com elementos profissionais.

📚 UFCD 0779 ✏️ Desenho e gráficos ⏱️ Sessões 9–10 💻 Separador Inserir
📖

Introdução

O PowerPoint disponibiliza um conjunto rico de ferramentas para enriquecer visualmente os diapositivos. Para além do texto, podes inserir formas, SmartArt, imagens, gráficos e tabelas — elementos que tornam a comunicação mais clara, visual e apelativa.

Todas estas ferramentas estão disponíveis no separador Inserir do friso. Ao selecionar qualquer objeto, aparecem automaticamente separadores contextuais com opções de formatação específicas para esse elemento.

O separador Inserir contém todas as ferramentas de desenho e inserção de objetos
💡 Ao selecionar um objeto (imagem, forma, gráfico), aparecem automaticamente separadores contextuais no friso com opções específicas para esse elemento.
🔷

Formas

As formas permitem criar elementos visuais — retângulos, círculos, setas, estrelas, balões de fala e muito mais. São ideais para destacar informação, criar diagramas simples ou adicionar elementos decorativos.

Como inserir uma forma

1
Vai a Inserir > Formas.
2
Escolhe a forma desejada da galeria.
3
Clica e arrasta no diapositivo para desenhar a forma.
4
Usa o separador Formato da Forma para personalizar preenchimento, contorno e efeitos.

Categorias de formas disponíveis

⬜

Retângulos e Quadrados

Formas básicas para caixas de texto, fundos e separadores visuais.

⭕

Elipses e Círculos

Ideais para ícones, marcadores e elementos circulares.

➡️

Setas e Conectores

Para indicar direções, fluxos e ligações entre elementos.

💬

Balões de Fala

Para citações, comentários e elementos de diálogo.

⭐

Estrelas e Faixas

Para destaques, prémios e elementos decorativos.

📐

Formas de Equação

Símbolos matemáticos e operadores para apresentações técnicas.

💡 Mantém premida a tecla Shift ao desenhar para criar formas perfeitas (círculo perfeito, quadrado perfeito).

Adicionar texto a uma forma

Faz duplo clique numa forma para adicionar texto diretamente dentro dela. O texto fica centrado automaticamente e pode ser formatado como qualquer outro texto.

🧩

SmartArt

O SmartArt permite criar diagramas profissionais pré-formatados para representar listas, processos, hierarquias, ciclos e relações — sem necessidade de criar os elementos manualmente.

Como inserir SmartArt

1
Vai a Inserir > SmartArt.
2
Escolhe a categoria e o tipo de diagrama.
3
Clica em OK para inserir o diagrama.
4
Clica em cada elemento para escrever o texto.
5
Usa o separador Design do SmartArt para alterar o estilo e as cores.

📋 ListaApresentar itens sem ordem específicaCaracterísticas, vantagens, recursos
➡️ ProcessoMostrar passos sequenciaisFluxo de trabalho, procedimentos
🔄 CicloRepresentar processos contínuosCiclo de vida, processos repetitivos
🏗️ HierarquiaMostrar estruturas organizacionaisOrganogramas, estruturas de equipa
🔗 RelaçãoMostrar ligações entre elementosComparações, conexões, dependências

💡 O SmartArt é ideal para substituir listas de texto simples por representações visuais mais apelativas e fáceis de compreender.

Imagens

As imagens tornam as apresentações mais apelativas e facilitam a compreensão de conceitos complexos. O PowerPoint permite inserir imagens de várias fontes.

💻

Imagens locais

Insere imagens guardadas no teu computador. Caminho: Inserir > Imagens > Este Dispositivo

🌐

Imagens online

Pesquisa e insere imagens diretamente da internet (requer ligação). Caminho: Inserir > Imagens > Imagens Online

📸

Captura de ecrã

Captura e insere uma imagem de qualquer janela aberta no computador. Caminho: Inserir > Captura de Ecrã

🎨

Ícones e Imagens de Stock

Biblioteca de ícones e imagens profissionais incluída no Microsoft 365. Caminho: Inserir > Ícones ou Imagens de Stock

Formatar imagens

Ao selecionar uma imagem, o separador Formato da Imagem permite:

  • Cortar: Remove partes indesejadas da imagem (Formato da Imagem > Cortar).
  • Estilos de imagem: Aplica molduras, sombras e efeitos predefinidos.
  • Ajustar cor e brilho: Modifica a saturação, tom e brilho da imagem.
  • Remover fundo: Remove automaticamente o fundo de uma imagem (Formato da Imagem > Remover Fundo).
  • Cortar para forma: Recorta a imagem no formato de uma forma geométrica.
📌 Usa sempre imagens com boa resolução. Evita esticar imagens além do seu tamanho original — ficam pixelizadas e prejudicam o aspeto profissional da apresentação.
📊

Gráficos

Os gráficos permitem representar dados de forma visual e clara, facilitando a compreensão de tendências, comparações e distribuições.

Como inserir um gráfico

1
Vai a Inserir > Gráfico.
2
Escolhe o tipo de gráfico na galeria.
3
Clica em OK — abre uma folha de cálculo para introduzir os dados.
4
Introduz os dados na folha de cálculo. O gráfico atualiza-se automaticamente.
5
Fecha a folha de cálculo. Usa o separador Design do Gráfico para personalizar.
Tipo de gráficoMelhor para
📊 Colunas / BarrasComparar valores entre categorias
📈 LinhasMostrar tendências ao longo do tempo
🥧 Circular (Pizza)Mostrar proporções de um todo
📉 ÁreaMostrar volumes acumulados ao longo do tempo
🔵 Dispersão (XY)Mostrar correlações entre duas variáveis
🍩 AnelComparar proporções de múltiplos conjuntos
💡 Escolhe o tipo de gráfico em função da mensagem que queres transmitir — não do que parece mais bonito. Um gráfico de linhas para tendências, colunas para comparações, circular para proporções.

Tabelas

As tabelas são ideais para organizar e apresentar informação estruturada de forma clara e comparável.

Como inserir uma tabela

1
Vai a Inserir > Tabela.
2
Arrasta o cursor para selecionar o número de linhas e colunas, ou clica em Inserir Tabela para definir manualmente.
3
Clica em cada célula para introduzir o conteúdo. Usa Tab para avançar para a célula seguinte.
4
Usa os separadores Estrutura da Tabela e Esquema para formatar e ajustar a tabela.

Dicas para tabelas eficazes

  • Cabeçalhos claros: A primeira linha deve identificar claramente o conteúdo de cada coluna.
  • Menos é mais: Evita tabelas com demasiadas colunas ou linhas — divide em várias tabelas se necessário.
  • Destaca a linha de cabeçalho: Usa uma cor de fundo diferente para a primeira linha.
  • Alinhamento consistente: Alinha os números à direita e o texto à esquerda.
  • Espaçamento adequado: Garante que o texto não fica demasiado próximo das bordas das células.
📐

Organizar Objetos

Quando um diapositivo tem vários objetos, é essencial saber organizá-los com precisão para criar um layout profissional.

📏

Alinhar e Distribuir

Seleciona vários objetos e usa Formato da Forma > Organizar > Alinhar para os alinhar entre si ou em relação ao diapositivo. A opção Distribuir espaça os objetos de forma uniforme.

🔼

Ordem de Sobreposição

Controla qual objeto fica à frente ou atrás: clica com o botão direito > Trazer para a Frente / Enviar para Trás.

🔗

Agrupar

Seleciona vários objetos e agrupa-os (botão direito > Agrupar) para os mover e redimensionar em conjunto. Para desagrupar: botão direito > Desagrupar.

🗂️

Painel de Seleção

Abre o Painel de Seleção (Início > Organizar > Painel de Seleção) para ver, selecionar, reordenar e ocultar objetos individualmente.

💡 Dica de produtividade

Usa as guias inteligentes do PowerPoint — ao mover objetos, aparecem linhas de guia automáticas que ajudam a alinhar com outros elementos do diapositivo.
